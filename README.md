# Vishal KVS — Personal portfolio

A warm, responsive portfolio with daylight and evening themes, persistent theme preference, accessible navigation, and direct project/contact links.

## Live website

https://therealvik3939-cloud.github.io/Portfolio/

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. Fonts load from Google Fonts with local fallbacks; the avatar loads from GitHub.

## Update

Edit `index.html` and commit to `main`. GitHub Pages publishes from the repository root.
